# Sales-Performance-Dashboard-
Sales Performance Dashboard 📊

About the Project

This is my personal project created using Microsoft Excel. I used PivotTables and PivotCharts to analyze sales data and create an interactive dashboard.

Tools Used

- Microsoft Excel 2013
- PivotTables
- PivotCharts
- Excel Filters
- Data Visualization

Dashboard Features

- Total Revenue
- Total Orders
- Quantity Sold
- Average Order Value
- Monthly Revenue
- Revenue by Region
- Revenue by Product Category
- Revenue by Sales Channel
- Top Products by Revenue
